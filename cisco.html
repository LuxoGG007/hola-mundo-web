TOOL_009 // CISCO IOS

CISCO CONFIG BUILDER.

Genera una configuración base para un switch Cisco IOS: hostname, SSH, VLAN de administración, VLANs de usuario, puerto access y puerto trunk.

Parámetros

Los secretos no se almacenan ni se solicitan. El resultado utiliza un marcador que debes reemplazar manualmente.

Configuración

Revisa la sintaxis según el modelo y versión de Cisco IOS antes de aplicarla.

CONFIGURACIÓN GENERADA 
—
El texto <CONFIGURE_SECURE_SECRET> es intencional. Reemplázalo en el equipo por una contraseña segura. NET//TOOLS no necesita conocerla.
